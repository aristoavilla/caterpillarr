# Simple Musician Template

A responsive, accessible one-page musician website built with plain HTML, CSS, and JavaScript.

## Preview

Open `index.html` in a browser.

## Customize

1. Replace the artist name, biography, release, dates, and contact details in `index.html`.
2. Replace the artwork and portrait placeholders with your images.
3. Point the streaming, social, ticket, and press-kit links to real destinations.
4. Adjust colors in the `:root` block of `styles.css`.

No build step or dependencies are required.
